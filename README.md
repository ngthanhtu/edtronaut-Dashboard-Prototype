# Edtronaut B2B Recruitment & Onboarding Suite - UI/UX Prototype

This is an interactive browser-based Frontend Prototype for Edtronaut's B2B recruitment management system. The project was designed to visualize the automation of candidate screening and competency evaluation through AI Job Simulations.

## 📸 Dashboard Mockup
![Recruiter Dashboard](assets/dashboard.png)

## 🚀 Project Overview
This product was developed as part of a Take-home Assignment for the IT BA / Product Owner role. The goal of this prototype is to provide highly tangible Product Requirements (PRD), enabling the Engineering team to easily understand the Data Logic and Business Rules prior to development.

## 🛠 Tech Stack
The project was built entirely using **Vanilla Web Technologies** (without any heavy frameworks) to ensure lightweight performance and clear static logic demonstration:
- **HTML5**: Semantic UI structuring.
- **CSS3 (Vanilla)**: Custom Design System (utilizing CSS Variables, Grid, and Flexbox).
- **JavaScript (ES6+)**: State Management, DOM Manipulation, Data Filtering, and Local Storage.

## 💡 Key Features
1. **Flow Manager**: Flexible configuration of recruitment pipelines (CV-first or Simulation-first).
2. **AI Dossier Drawer**: Detailed view of AI-analyzed candidate competencies, featuring Radar charts and Fraud/Plagiarism flags.
3. **Pipeline Management**: Ability to bulk-update candidate statuses (Shortlist, Interview, Offer, Onboarding).
4. **Data Persistence**: Auto-saves candidate statuses and job configurations into the browser's Local Storage.

## 💻 How to Run
1. Download or clone this repository to your local machine.
2. Open the `index.html` file using any modern web browser (Chrome, Safari, Edge, etc.).
3. *(Optional)* For the best experience, open the project folder in Visual Studio Code and use the Live Server extension.
